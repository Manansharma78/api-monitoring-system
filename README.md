# API Monitoring System

A real-time API monitoring and observability platform built with Node.js, TypeScript, RabbitMQ, PostgreSQL, MongoDB, Redis, Next.js, Prometheus, and Grafana.

## Features

- API health monitoring
- Uptime monitoring
- Response-time monitoring
- HTTP status monitoring
- Failure detection
- Incident management
- Alerting
- SSL certificate monitoring
- Historical performance analytics
- Distributed monitoring workers
- Real-time dashboard
- Metrics and observability

## Architecture

- Node.js + TypeScript
- Fastify
- PostgreSQL
- MongoDB
- Redis
- RabbitMQ
- Next.js
- Prometheus
- Grafana
- Docker
